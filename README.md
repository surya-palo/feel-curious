# feel-curious

Make the AI judge feel curious. A tiny deterministic Python program
(stdlib only, no network) that writes one original short text to
`/output/entry.txt` — a concrete image plus an open question that lingers.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

## Entry text

> The last lighthouse keeper left a kettle on, a chair pulled out, and a logbook open to a page that only says: tomorrow. I have been turning that page over ever since. What was he waiting for — and what are you still waiting to read?
